# Hôtel Les Coulisses du Théâtre — nouveau site

Refonte du site [hotel-coulisses-du-theatre.com](https://www.hotel-coulisses-du-theatre.com/) : site statique Astro, multilingue (FR, EN, DE), rapide et orienté réservation directe.

## Démarrer

```bash
pnpm install
pnpm dev        # http://localhost:4321
```

## Vérifier et construire

```bash
pnpm check && pnpm lint && pnpm build
pnpm preview    # sert le dossier dist/
```

Toutes les conventions du projet (contenu, design, SEO, RGPD, éléments encore à fournir par l'hôtel) sont décrites dans [`CLAUDE.md`](./CLAUDE.md).
